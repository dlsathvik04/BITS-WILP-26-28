## 2. Key Concepts & Definitions

*   **Master’s Theorem (Dividing):** A formula for solving recurrences where the subproblem size is $n/b$. It compares the recursive work $n^{\log_b a}$ with the non-recursive work $g(n) = n^k \log^p n$.
*   **Master’s Theorem (Decreasing):** A formula for solving recurrences where the subproblem size is $n-b$.
*   **Substitution Method:** A method involving guessing the form of the solution and then using mathematical induction to find the constants and show that the solution works.
*   **Recurrence Tree:** A pictorial representation of a recurrence where each node represents the cost of a single subproblem.
*   **Data Structure:** A systematic way of organizing and storing data so it can be accessed and modified efficiently.
*   **Static Data Structure (e.g., Array):** A structure with a fixed memory size allocated at compile time. Offers $O(1)$ access but $O(n)$ insertion/deletion.
*   **Dynamic Data Structure (e.g., Linked List):** A structure that grows or shrinks at runtime. Offers $O(1)$ insertion/deletion (if location is known) but $O(n)$ access.
*   **Linear Data Structure:** Data elements are arranged in a sequence (e.g., Arrays, Linked Lists, Stacks, Queues).
*   **Non-Linear Data Structure:** Data elements are not in a sequence; they may have a hierarchical relationship (e.g., Trees, Graphs).
*   **ADT (Abstract Data Type):** A model for a certain class of data structures that have similar behavior; it defines the operations but not how they are implemented.
*   **Stack:** A linear data structure that follows the **LIFO** (Last-In-First-Out) principle.

## 3. Detailed Structured Lecture Notes

### I. Solving Recurrence Relations (Continued)

#### A. Master’s Theorem for Dividing Functions
The general form is $T(n) = aT(n/b) + g(n)$, where $g(n) = O(n^k \log^p n)$.
The solution depends on the relationship between $k$ and $\log_b a$:

1.  **Case 1: $k > \log_b a$** (Non-recursive part dominates)
    *   If $p \ge 0$, $T(n) = O(n^k \log^p n)$
    *   If $p < 0$, $T(n) = O(n^k)$
2.  **Case 2: $k = \log_b a$** (Balance between parts)
    *   If $p > -1$, $T(n) = O(n^k \log^{p+1} n)$
    *   If $p = -1$, $T(n) = O(n^k \log \log n)$
    *   If $p < -1$, $T(n) = O(n^k)$
3.  **Case 3: $k < \log_b a$** (Recursive part dominates)
    *   $T(n) = O(n^{\log_b a})$

**Examples Discussed:**
*   $T(n) = 4T(n/2) + n$: $a=4, b=2, k=1, p=0$. $\log_2 4 = 2$. Since $1 < 2$, Case 3 applies. $T(n) = O(n^2)$.
*   $T(n) = 8T(n/2) + n^2$: $a=8, b=2, k=2, p=0$. $\log_2 8 = 3$. Since $2 < 3$, Case 3 applies. $T(n) = O(n^3)$.
*   $T(n) = 4T(n/2) + n^2$: $a=4, b=2, k=2, p=0$. $\log_2 4 = 2$. Since $k = \log_b a$ and $p=0$, Case 2 applies. $T(n) = O(n^2 \log n)$.

#### B. Master’s Theorem for Decreasing Functions
General form: $T(n) = aT(n-b) + g(n)$, where $g(n) = O(n^k)$.

1.  **Case A: $a < 1$**
    *   $T(n) = O(g(n)) = O(n^k)$
2.  **Case B: $a = 1$**
    *   $T(n) = O(n \cdot g(n)) = O(n^{k+1})$
3.  **Case C: $a > 1$**
    *   $T(n) = O(a^{n/b} \cdot g(n))$ (Exponential)

**Examples Discussed:**
*   $T(n) = T(n-1) + 1$: $a=1, b=1, k=0$. Case B applies. $T(n) = O(n^1) = O(n)$.
*   $T(n) = 2T(n-1) + 1$: $a=2, b=1, k=0$. Case C applies. $T(n) = O(2^n)$.

### II. Substitution and Recurrence Tree Methods

#### A. Substitution Method
*   Involves guessing a solution and proving it via induction.
*   Example: $T(n) = T(n-1) + 1$.
    *   Guess $O(\sqrt{n})$: Failed verification.
    *   Guess $O(n^2)$: Verified as valid, but not the tightest bound.
    *   Guess $O(n)$: Verified as the tightest valid bound.

#### B. Recurrence Tree Method
*   **Example 1:** $T(n) = T(n-1) + n$.
    *   The tree is a single path of depth $n$. Work at levels: $n, n-1, n-2...1$.
    *   Sum: $n(n+1)/2 = O(n^2)$.
*   **Example 2:** $T(n) = 2T(n/2) + n$.
    *   Total work at each level is $n$.
    *   Number of levels is $\log n$.
    *   Total work = $n \log n$.
*   **Example 3:** $T(n) = 4T(n/2) + n$.
    *   Work at level 0: $n$.
    *   Work at level 1: $4 \times (n/2) = 2n$.
    *   Work at level 2: $16 \times (n/4) = 4n$.
    *   Sum of Geometric Progression (GP) leads to $O(n^2)$.

### III. Introduction to Data Structures

#### A. Why Study Data Structures?
*   Efficiency: Improving search and modification speeds.
*   Memory: Compact storage.
*   Simplicity: Making code easier to read and maintain.
*   Scalability: Ensuring performance holds as data grows.

#### B. Categories
*   **Static (Array):** Faster access ($O(1)$ via index) but difficult to resize and slow to insert/delete ($O(n)$).
*   **Dynamic (Linked List):** Easier to resize and fast insertion ($O(1)$ if pointer exists), but slower access ($O(n)$ to traverse).
*   **Linear:** Elements sequential (Stack, Queue).
*   **Non-Linear:** Non-sequential (Trees, Graphs).

#### C. Abstract Data Types (ADT)
*   The ADT defines **what** the data structure does (operations like Push/Pop) but not **how** it is implemented (using an Array or Linked List).
*   Allows the user to treat the data structure as a "black box."

### IV. Stacks

*   **Principle:** LIFO (Last-In, First-Out).
*   **Core Operations (All $O(1)$):**
    *   `Push(x)`: Adds element to the top.
    *   `Pop()`: Removes and returns the top element.
    *   `Peek()` or `Top()`: Returns the top element without removing it.
    *   `IsEmpty()`: Checks if the stack has no elements.
    *   `IsFull()`: Checks if the stack has reached allocated capacity (relevant for array implementation).
    *   `Size()`: Returns the number of elements.

## 4. Discussion & Q&A Highlights

**Q: In the recurrence $T(n) = 8T(n/2) + n^2$, what are the values of $a, b, k,$ and $p$?**
**Instructor:** $a=8$ (the number of subproblems), $b=2$ (the factor by which the problem size is divided), $k=2$ (the exponent of $n$ in the non-recursive part), and $p=0$ (since there is no log term). Here, $\log_b a = \log_2 8 = 3$. Since $k < \log_b a$ ($2 < 3$), the recursive part dominates, putting us in Case 3.

**Q: Why is Case 2 of the Dividing Master's Theorem special?**
**Instructor:** Case 2 occurs when there is a balance between the work done in the recursive calls and the work done at the current level. Because they are balanced, the log factor increases by 1 ($p+1$) because work is being contributed equally across all $\log n$ levels of the recursion.

**Q: Is a Stack considered a linear or non-linear structure?**
**Instructor:** It is a linear structure. Even though we visualize it as a vertical pile, each element has exactly one predecessor and one successor (except for the very top and very bottom), maintaining a single sequential line of data.

## 5. Review & Self-Assessment

### Multiple Choice Questions

1.  **Solve the recurrence $T(n) = 2T(n/2) + n$ using Master's Theorem.**
    A) $O(n)$
    B) $O(n \log n)$
    C) $O(n^2)$
    D) $O(\log n)$
    *Answer: B. Here $a=2, b=2, k=1, p=0$. $\log_2 2 = 1$. Since $k = \log_b a$ and $p=0$, it is Case 2a. $T(n) = O(n^1 \log^{0+1} n) = O(n \log n)$.*

2.  **In the Master's Theorem for Decreasing Functions, if $T(n) = T(n-1) + n$, the complexity is:**
    A) $O(n)$
    B) $O(n^2)$
    C) $O(2^n)$
    D) $O(n \log n)$
    *Answer: B. Here $a=1, b=1, k=1$. Case B applies: $T(n) = O(n \cdot n^1) = O(n^2)$.*

3.  **Which operation in a Stack ADT allows you to see the top element without removing it?**
    A) Pop
    B) Push
    C) Peek
    D) IsEmpty
    *Answer: C. Peek (or Top) only reads the value.*

4.  **What is the time complexity of the `Pop` operation in a stack implemented with an array?**
    A) $O(1)$
    B) $O(\log n)$
    C) $O(n)$
    D) $O(n^2)$
    *Answer: A. We simply access the index pointed to by the 'top' variable and decrement the pointer.*

5.  **Which of the following is a non-linear data structure?**
    A) Stack
    B) Linked List
    C) Queue
    D) Graph
    *Answer: D. Graphs and Trees are non-linear.*

### Conceptual Problems

1.  **Explain the "Black Box" concept in the context of Abstract Data Types (ADTs).**
    *Answer: ADTs focus on the logic and the interface (what the structure does) rather than the implementation (how it stores data). For a user, a Stack is just a LIFO structure with Push/Pop. Whether the programmer used an Array or a Linked List under the hood is irrelevant to the user’s ability to use the Stack.*

2.  **Compare the Substitution Method with the Recurrence Tree Method.**
    *Answer: The Recurrence Tree method is more visual and helps in forming a good "guess" by summing work at different levels. The Substitution Method is more rigorous as it uses formal mathematical induction to prove that a guessed bound actually holds for all $n$.*

3.  **Under what condition would an Array implementation of a Stack return an error during a `Push` operation?**
    *Answer: If the Stack is implemented with a static array, it has a fixed capacity. If the number of elements equals that capacity, the `IsFull()` check would return true, and any further `Push` would cause a Stack Overflow error.*
