## 2. Core Topics For Self Study

* **Life Cycle and Economics of Embedded System Design:**
* Cost modeling: Non-Recurring Engineering (NRE) costs versus per-unit production costs.


* Economic trade-offs in mass production to drive down unit costs.




* **System and User-Centric Design Metrics:**
* Time-to-prototype versus time-to-market trade-offs and market window dynamics.


* Power optimization techniques (sleep modes, low-power modes, frequency scaling).


* Physical design metrics: Size, density, weight constraints, and ergonomic single-handed operation.


* System reliability and verification triad: Testing vs. Validation vs. Verification.


* Mechanical and electrical safety tolerances (vibrations, surges, dropouts).




* **Processing Unit Paradigms:**
* Microprocessors vs. Microcontrollers (on-chip vs. off-chip integration of peripherals and memory).


* RISC vs. CISC instruction decoder complexity (ARM Cortex-M4 as an Advanced RISC Machine).


* Specialized processors: DSPs/IPs with Multiply-Accumulate (MAC) units and Floating Point Units (FPUs).


* Hardware customization: ASICs, ASIPs, and field-reconfigurable logic using FPGAs for intellectual property (IP) confidentiality.




* **Memory Architectures and Technologies:**
* Von Neumann vs. Harvard memory organization (unified vs. separate address spaces for code and data).


* Volatile memories: SRAM (flip-flop based, high speed, cache usage, 4–6 transistors/cell) vs. DRAM (capacitor-based dynamic storage, refresh cycles, higher density, 2 transistors/cell).


* Non-volatile memories: NVRAM, EEPROM (byte-level access for firmware/boot code), and Flash memory (block-erasable storage).




* **Interfacing, Power, and Timing Subsystems:**
* Parallel interfaces (PCI, SCSI) vs. Serial interfaces (UART/USART, SPI, $\text{I}^2\text{C}$, USB).


* Analog-to-Digital (ADC) and Digital-to-Analog (DAC) signal conversion for resistive, capacitive, and inductive loads.


* Power regulation: Linear regulators, switching regulators (buck vs. boost DC-to-DC conversion), and supervisor circuits (brownout timers/protection, reset circuits).


* Clock generation and clock sources: Crystal oscillators (piezoelectric effect), LC tank circuits, RC circuits, Phase-Locked Loops (PLLs) for frequency scaling, and Real-Time Clocks (RTCs).

## 3. Key Concepts & Definitions

* **NRE Cost (Non-Recurring Engineering Cost):** The one-time monetary investment required for the research, design, and development (R&D) phase of an embedded product. It does not recur during production unless major upgrades or feature redesigns take place.


* **Unit Cost:** The recurring monetary cost incurred for producing every individual copy or unit of a product, primarily dictated by raw material procurement, peripheral components, and assembly expenses.


* **Throughput:** The measure of execution performance defined as the number of instructions executed per unit of time, typically quantified in MIPS (Million Instructions Per Second).


* **Prototype:** A functional working model of a system built to test, evaluate, and validate functional requirements and identify malfunctions against client specifications before committing to full-scale manufacturing.


* **Time to Market:** The cumulative duration required to transition a product from initial design concept through development, prototyping, and final manufacturing until it is released for commercial sale.


* **Software Update vs. Software Upgrade:** An *update* enhances the performance, efficiency, or bug fixes of existing features, whereas an *upgrade* introduces entirely new functionalities or operational features to the system.


* **Testing:** The process of providing random, corrupted, or edge-case inputs to a system to evaluate how it behaves and reacts under adverse conditions.


* **Validation:** The process of evaluating the operational system to verify whether it meets all explicitly defined functional requirements.


* **Verification:** The process (typically conducted via technical audits, supervision, or third-party reviews) of ensuring that the design implementation aligns correctly with high-level client specifications and intended architectural paths.


* **Safety:** The probability that a system will cause physical, electrical, or mechanical harm to the end user, which must be engineered to tend toward zero.


* **Firmware:** Hardware-specific low-level executable code stored in non-volatile memory (such as ROM, EEPROM, or Flash) that initializes and controls embedded hardware.


* **MAC Unit (Multiply-Accumulate Unit):** A specialized hardware execution block in DSPs and Image Processors designed to perform rapid, continuous multiplication followed by cumulative addition ($A + (B \times C)$) in a single operational pipeline.


* **ASIC (Application-Specific Integrated Circuit):** An integrated circuit customized exclusively for a specific end-use application rather than general-purpose computing.


* **ASIP (Application-Specific Instruction-set Processor):** A processing unit whose architectural instruction set is tailored specifically to accelerate dedicated domain tasks.


* **FPGA (Field-Programmable Gate Array):** A semiconductor device based on a matrix of configurable logic gates that can be electrically programmed by an engineer in-house, enabling proprietary circuit implementation without exposing schematic blueprints to external fabrication foundries.


* **SRAM (Static RAM):** Volatile random-access memory built using flip-flop latching circuitry (typically 4 to 6 transistors per cell) that retains data statically as long as power is applied without requiring periodic refreshing.


* **DRAM (Dynamic RAM):** Volatile random-access memory built with capacitor-based charge storage (using approximately 2 transistors per cell) requiring periodic refresh cycles to prevent charge leakage and data loss.


* **NVRAM (Non-Volatile RAM):** Random-access memory combining the fast, random accessibility of RAM with non-volatile retention characteristics that persist even when primary power is removed.


* **EEPROM:** Electrically Erasable Programmable Read-Only Memory; non-volatile sequential memory that supports byte-by-byte read and write operations.


* **Flash Memory:** A high-density non-volatile ROM variant that executes read/write access and erasure in blocks rather than individual bytes.


* **Linear Voltage Regulator:** A power regulation device that provides a stable, transient-free output voltage by adjusting resistance linearly.


* **Buck Converter:** A switched-mode DC-to-DC converter designed to step down a higher DC input voltage to a lower stabilized DC output voltage.


* **Boost Converter:** A switched-mode DC-to-DC converter designed to step up a lower DC input voltage to a higher stabilized DC output voltage.


* **Brownout Protection:** A supervisory safeguarding mechanism that senses when supply voltage drops below a critical threshold (e.g., falling from 220V to 150V) and triggers an immediate interrupt to the CPU, allowing the system a brief time window to secure runtime states before total power failure.


* **Phase-Locked Loop (PLL):** A control circuit utilizing a Voltage-Controlled Oscillator (VCO) to dynamically scale and configure clock frequencies for optimizing system operating speeds and power consumption.


* **Real-Time Clock (RTC):** An independent, ultra-low-power timer module backed by a dedicated auxiliary source (e.g., coin-cell battery) that continuously maintains current time and calendar tracking regardless of main system power states.

## 4. Detailed Structured Technical Lecture Notes

### I. Embedded System Design Requirements & Life Cycle Economics

Embedded system design is governed by both technical specifications and commercial/economic viability across its complete operational lifecycle:

* **Lifecycle Phases:** Research & Development (R&D) $\rightarrow$ Development & Production $\rightarrow$ Operation & Maintenance.


* **Economic Parameters:**
* **Non-Recurring Engineering (NRE) Cost:** One-time monetary expenditure associated with R&D, functional design, schematic capture, and initial layout. NRE cost is not repeated across production batches unless a substantial redesign or hardware upgrade occurs.


* **Unit Cost:** The recurring operational expenditure to produce each physical unit or copy (raw materials, microchips, printed circuit boards, mechanical enclosures).


* **Economies of Scale:** Mass production drastically reduces the effective unit cost across large manufacturing runs.




* **Performance Metrics:**
* Measured in task execution time, multitasking latency, or processing throughput.


* Quantified using Million Instructions Per Second (MIPS).




* **Time-to-Prototype vs. Time-to-Market:**
* *Time-to-Prototype:* Speed at which engineers iterate from concept to a verifiable functional model. Initial scratch development takes longer, while revision cycles must be executed rapidly.


* *Time-to-Market:* Total span including design, prototyping, fabrication, testing, and full manufacturing deployment.


* In modern consumer markets (e.g., mobile phones), commercial lifespans are roughly 6 months. A design window of 2 months leaves a release at Month 3, requiring complete capital investment recovery within a 2-to-3-month window before product obsolescence.





### II. Power Optimization and User-End Paradigms

Embedded systems are frequently deployed in standalone, battery-backed, portable environments where power draw directly impacts battery lifespan:

* **Battery Mechanics:** Longer battery runtimes reduce recharge frequency. Because battery longevity degrades with charge cycles, reducing recharge frequency directly extends the physical operational life of the battery.


* **Power Optimization Strategies:**
* Implementing processor sleep modes and peripheral low-power states.


* AC-powered systems have less restrictive power constraints, but power optimization remains a baseline criterion across all embedded designs.




* **User-Centric Constraints:**
* *Operational Flexibility:* Providing options to enable or disable features seamlessly without incurring extra hardware costs.


* *Maintainability:* Facilitating routine preventive maintenance, failure repairs, non-disruptive software updates (performance tuning), and upgrades (new features).


* *Correctness & Quality Assurance:* Executed via testing (response to invalid/corrupt inputs), validation (conformance to functional requirements), and verification (auditing that design tracks high-level client needs).


* *Safety Compliance:* Probability of user harm must tend to zero ($P(\text{Harm}) \to 0$). Encompasses electrical isolation (absorption of line surges, preventing leakages) and mechanical isolation (withstand vehicle vibration profiles in ECUs, water ingress protection, eliminating explosion hazards in Li-ion cells).


* *Ergonomics and Aesthetics:* Optimum dimensions and weight density. For handheld devices, screens must allow full single-handed reach to all four display corners without requiring two hands, balanced against clear visual readability and simple, single-touch default controls.





### III. System Hardware Architecture & Processing Unit Selection

A generic embedded system block diagram integrates a processing unit, clocking, address/instruction decoders, internal/external memories, timing units, and I/O controllers:

```
+-----------------------------------------------------------------------+
|                       Embedded System Architecture                     |
|                                                                       |
|  +---------------------+        +----------------------------------+  |
|  |   Processing Unit   |<------>| Address & Instruction Decoders   |  |
|  | (ARM, MCU, DSP, etc)|        +----------------------------------+  |
|  +----------+----------+                         |                    |
|             |                                    v                    |
|             |                   +----------------------------------+  |
|             |<----------------->| Memory Blocks                    |  |
|             |                   | - Program (ROM / Flash / EEPROM) |  |
|             |                   | - Data (SRAM / DRAM / NVRAM)     |  |
|             |                   +----------------------------------+  |
|             |                                                         |
|             |        +-------------------+     +-------------------+  |
|             +------->| Timers / Counters |     | ADC / DAC Units   |  |
|             |        | (RTC, Watchdog)   |     +-------------------+  |
|             |        +-------------------+               |            |
|             |                                            v            |
|             |        +-------------------+     +-------------------+  |
|             +------->| Power Management  |     | Communication I/O |  |
|                      | (Regulators, BOD) |     | (SPI, I2C, UART)  |  |
|                      +-------------------+     +-------------------+  |
+-----------------------------------------------------------------------+

```

* **Processing Unit Classifications:**
* *Microcontroller (MCU):* Integrates the CPU core, memory blocks, clock circuitry, timers, and programmable General-Purpose Input/Output (GPIO) pins directly onto a single monolithic die.


* *Microprocessor (MPU):* Contains only the CPU core on-chip. Memory, bus arbiters, decoders, and I/O interfaces exist as external, hardwired peripherals. External I/O pins cannot be directly programmed as generic application-level GPIOs.


* *Instruction Decoders (RISC vs. CISC):* CISC decoders are complex due to large, variable-length instruction sets. RISC decoders are simple and streamlined. The target laboratory architecture is the **ARM Cortex-M4**, an Advanced RISC Machine.


* *Digital Signal Processors (DSP) & Image Processors (IP):* Specialized engines incorporating hardware **Multiply-Accumulate (MAC)** units. Standard microprocessors process operations sequentially, whereas signal processing evaluates repetitive Sum-of-Products (SOP) expansions such as Fourier series expansions:



$$f(\theta) = \sum_{n} A_n \sin(n\theta) + \sum_{n} B_n \cos(n\phi)$$



The MAC unit multiplies the incoming magnitude and phase parameter and accumulates it to the previous running sum in single-cycle operations.


* *Floating Point Units (FPU):* Standard processors natively execute integer arithmetic only; real-time floating-point operations require dedicated hardware FPUs.


* *ASIC and ASIP:* Custom-designed silicon for a singular dedicated task, providing near-zero error probabilities, high execution performance, and minimal power consumption.


* *FPGA:* Used when application-specific logic must remain proprietary. Instead of exposing intellectual property (IP) blueprints to third-party foundries, companies procure generic gate arrays structured in rows and columns and configure their logic in-house.


* *Embedded Processors:* Domain-specific dedicated processors found in keyboards, calculators, modems, hard disk drive (HDD) controllers, and overhead projectors (OHP) that cannot be repurposed for alternate tasks.


* *Commercial Examples:* x86, ARM, AVR, PIC, 68K, MIPS, PowerPC.





### IV. Memory System Architectures & Technologies

* **Memory Organizations:**
* *Harvard Architecture:* Physically distinct storage spaces, buses, and address spaces for Program Memory (code) and Data Memory.


* *Von Neumann Architecture:* Single, unified physical address space and shared bus shared by both code instructions and execution data.




* **Volatile Memory (RAM):**
* *Static RAM (SRAM):* Digital flip-flop storage. Holds states indefinitely without refresh cycles as long as power remains uninterrupted. Very high access speeds; ideal for on-chip cache memory. High unit cost and lower bit density; requires 4 to 6 transistors per bit cell.


* *Dynamic RAM (DRAM):* Stores data charges on internal parasitic transistor capacitances. Requires only 2 transistors per cell, enabling massive density and low cost (gigabyte scale). Capacitors naturally discharge over time, requiring periodic **refresh cycles** to prevent data corruption. Slower access speed than SRAM.


* *Non-Volatile RAM (NVRAM):* Combines high-speed random access with non-volatile retention upon power collapse. Has higher power demands and reduced storage density compared to standard DRAM due to added cell complexity.




* **Non-Volatile Memory (ROM / Firmware Storage):**
* *EEPROM:* Electrically Erasable Programmable Read-Only Memory. Byte-accessible read/write cycles. Highly secure for critical bootup codes and low-level firmware, but writes are slow (writing hundreds of kilobytes may take 10 to 15 minutes).


* *Flash Memory:* Block-accessible ROM variant. Writing can occur at the byte level, but operations and erasures occur across fixed memory blocks (e.g., a 512-byte block). Fast read/write performance; ideal for storing application images and database structures (e.g., smartphone contact lists allocate whole blocks regardless of string character length).





### V. Peripheral Interfacing, Power Subsystems, & Clocking

* **Input/Output Interfaces:**
* *Parallel Interfaces:* Peripheral Component Interconnect (PCI) and Small Computer System Interface (SCSI) transmit multiple data bits (8, 10, 12+ bits) simultaneously over parallel traces. Common in high-speed legacy printing/scanning, but rarely used in modern pin-constrained microcontrollers.


* *Serial Interfaces:* Save critical GPIO resources by streaming data over single-line channels. Includes UART/USART (asynchronous/synchronous serial communication used for GPS and GSM modules), SPI (Serial Peripheral Interface for high-speed board-level peripherals), $\text{I}^2\text{C}$ (Inter-Integrated Circuit bus restricted to short-distance, inter-IC onboard routing spanning a few inches), and USB (Universal Serial Bus).


* *Wireless Interfaces:* Short-to-medium range modules operating in the standard $2.4\text{ GHz}$ industrial band (Bluetooth, Wi-Fi / Wireless Fidelity, ZigBee) alongside cellular GSM modules.


* *Data Converters (ADC & DAC):* Real-world physical phenomena (temperature, pressure, humidity) are analog, requiring an Analog-to-Digital Converter (ADC) at the input/sensor stage. Digital-to-Analog Converters (DAC) are required to drive analog inductive loads (actuators, throttle valves, motors). Purely capacitive loads (LCD screens) or resistive loads (LEDs, buzzers) do not require a DAC and can be driven directly via digital I/O lines.




* **Power Supply Subsystems:**
* *Voltage Regulators:* Suppress noise, load variations, and source transients. Linear regulators step down voltage linearly without introducing high-frequency transient switching noise.


* *Switching Regulators (DC-DC):* Convert unregulated input supplies into distinct system operating levels (e.g., stepping $12\text{ V}$ down to $5\text{ V}$ or $3.3\text{ V}$). Step-down conversion uses **Buck Converters**; step-up conversion uses **Boost Converters**. AC-to-DC converters are integrated into offline mains chargers.


* *Supervisory Circuits & Brownout Protection:* Monitors supply rails for abrupt voltage decay (e.g., dropping from $220\text{ V}$ down to a trip threshold of $150\text{ V}$). Upon crossing the threshold, a brownout timer triggers a high-priority CPU interrupt. The residual decay window (from $150\text{ V}$ down to $50\text{ V}$) provides the finite execution time needed to safely park hardware, write critical runtime variables, and protect the OS kernel prior to complete shutdown.




* **Clock Generation & Management:**
* System power consumption scales directly with operating frequency:

$$P \propto f$$


* *Embedded Design Rule on Frequency:* Never over-specify processing frequency. If an operation allows a 5-second deadline, running an over-clocked system that finishes in 3 seconds wastes energy during the resulting 2-second idle window. Operating frequencies should be scaled down so tasks finish within a tight safety margin ($\le 10\%$, or between $4.5$ and $5.0\text{ seconds}$).


* *Crystal Oscillators:* Exploit the piezoelectric effect, where mechanical compressive force (stress) or elongative force (strain) applied to a shaped quartz crystal generates precise, high-frequency electrical signals (Megahertz to Gigahertz). Fixed-frequency output.


* *LC Tank Circuits & RC Oscillators:* Inductor-Capacitor circuits generate medium frequencies (hundreds of kHz to few MHz); Resistor-Capacitor circuits generate lower-frequency clocks. Both produce static, unalterable frequencies once physical component values are set.


* *Phase-Locked Loops (PLLs):* Employ Voltage-Controlled Oscillators (VCO) to synthesize and dynamically scale clock frequencies under program control, providing runtime power-scaling capabilities.


* *Real-Time Clock (RTC):* Independent low-frequency timer powered by an isolated auxiliary coin-cell battery, ensuring continuous tracking of system date and time during main system power outages.
